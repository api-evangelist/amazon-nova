# Amazon Nova (amazon-nova)
Amazon Nova is a new generation of frontier intelligence models from Amazon that deliver a compelling combination of accuracy, speed, and cost. Amazon Nova models are accessible through Amazon Bedrock and are designed for a wide range of tasks including text, image, and video understanding.

## APIs

### Amazon Nova API
The Amazon Nova API provides programmatic access to Amazon Nova foundation models through Amazon Bedrock for text, image, and video generation, understanding, and reasoning tasks.
